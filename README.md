A Windows application that tracks Fortnite chest openings by analyzing locally saved match replay files.

## Features

- Automatically scans Fortnite replay files.
- Tracks chest openings across matches.
- Displays total chest statistics.
- Maintains match history.
- Calculates Pirate Shop Access drop probabilities.
- Simulates chest openings.

## Pirate Shop Access

The estimated Pirate Shop Access drop rate is **1 in 137,500 chests**.

The tracker includes probability calculations to help you understand your chances based on your total chest openings.

Drop rates are random. Reaching the estimated drop rate does not guarantee receiving the reward.

## Installation

1. Download the latest release.
2. Extract the ZIP file.
3. Open the extracted folder.
4. Run `Start Chest Tracker FIXED.bat`.
5. Allow the application to install any required dependencies.
6. Launch the tracker.

## Usage

1. Enable replay recording in Fortnite.
2. Play a match normally.
3. Open Fortnite Chest Tracker.
4. Select or scan your replay files.
5. View your chest statistics and match history.

## Requirements

- Windows 10 or Windows 11.
- Fortnite replay files.
- Internet connection for initial dependency installation, if required.

## Safety

The application reads locally saved Fortnite replay files.

It does not:
- Inject code into Fortnite.
- Read game memory.
- Modify game files.
- Automate gameplay.
- Send inputs to Fortnite.

The application operates independently of the running game. However, this does not constitute an official Epic Games endorsement or guarantee of compliance with its policies.

## Troubleshooting

**No chests detected**
- Make sure replay recording is enabled.
- Check that the replay file is valid.
- Try scanning another match.

**Application does not start**
- Make sure all extracted files are present.
- Run `Start Chest Tracker FIXED.bat` again.
- Check that required dependencies installed successfully.
